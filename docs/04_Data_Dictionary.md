# Data dictionary

All monetary values must be on the same annual basis and scale.

| Field | Definition |
|---|---|
| `revenue` | Annual net sales / revenue |
| `gross_profit` | Revenue less cost of revenue |
| `ebit` | Earnings before interest and tax |
| `net_income` | Profit or loss after tax |
| `operating_cash_flow` | Cash generated by operations |
| `current_assets` / `current_liabilities` | Balance-sheet current accounts |
| `cash_and_equivalents` | Cash and near-cash investments |
| `inventory` | Inventory balance |
| `total_assets` / `total_liabilities` | Total balance-sheet assets and liabilities |
| `shareholders_equity` | Book equity |
| `retained_earnings` | Cumulative retained earnings |
| `long_term_debt` | Non-current interest-bearing debt |
| `market_capitalization` | Fiscal-period-end market value of equity |
| `shares_outstanding` | Period-end shares outstanding |
